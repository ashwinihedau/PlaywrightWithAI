# Chapter 02 — JavaScript Basics

This folder covers the absolute basics of JavaScript syntax, focusing on variable declaration and reassignment.

---

## Files

| File | Description |
|------|-------------|
| `05_JS_Basics.js` | Demonstrates basic variable declaration using `var`, logging the value, and redeclaring the same variable. |

---

## How to Run

Open a terminal in this folder and execute the file with Node.js:

```bash
node 05_JS_Basics.js
```

---

## Topics Covered

- Declaring variables with `var`
- Re-declaring variables
- Logging values to the console

> **Note:** In modern JavaScript, `let` and `const` are preferred over `var` to avoid scope-related issues.
