# Chapter 01 — Basics

This folder contains the foundational JavaScript examples to get started with the PlaywrightWithAI learning journey.

---

## Files

| File | Description |
|------|-------------|
| `01_Basics.js` | Introduction to variables and `console.log`. Declares a variable `a` with value `10` and prints it. |
| `02_HotCode.js` | Demonstrates the concept of **hot code** and how JavaScript engines optimize frequently executed code via the pipeline: Parser → AST → Interpreter → Profiler → Compiler → Optimized Code. |
| `03_Js_Verify_Setup.js` | Verifies the Node.js runtime environment by printing `process.platform`, `process.arch`, and `process.version`. |

---

## How to Run

Open a terminal in this folder and execute any file with Node.js:

```bash
node 01_Basics.js
node 02_HotCode.js
node 03_Js_Verify_Setup.js
```

---

## Topics Covered

- Variable declaration with `let`
- Understanding JavaScript engine optimization (hot code)
- Verifying Node.js installation and environment details
