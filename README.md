# PlaywrightWithAI

Welcome to **PlaywrightWithAI** — a hands-on learning repository that covers JavaScript fundamentals, best practices, and modern testing concepts. This repo is structured chapter-by-chapter to make learning progressive and easy to follow.

---

## Repository Structure

| Chapter | Folder | Description |
|---------|--------|-------------|
| **Chapter 01** | `chapter_01_Basics` | JavaScript basics — variables, `console.log`, hot code optimization, and verifying your Node.js setup. |
| **Chapter 02** | `chapter_02_JavaScript_Basics` | Core JavaScript syntax — variable declaration with `var`, reassignment, and logging. |
| **Chapter 03** | `chapter_03_Identifierand _literal` | Identifiers, literals, naming conventions (`camelCase`, `PascalCase`, `snake_case`, etc.), comments, and VS Code keyboard shortcuts for macOS & Windows. |

---

## How to Run the Examples

Each chapter contains standalone `.js` files. You can run any file using Node.js from your terminal:

```bash
# Example: run a file from Chapter 01
node chapter_01_Basics/01_Basics.js

# Example: run a file from Chapter 03
node chapter_03_Identifierand\ _literal/js_Identifier_rule.js
```

> Make sure you have [Node.js](https://nodejs.org/) installed on your system.

## Chapter Details

### Chapter 01 — Basics
- **`01_Basics.js`** — Introduction to variables and `console.log`.
- **`02_HotCode.js`** — Explains how JavaScript engines optimize frequently executed (hot) code.
- **`03_Js_Verify_Setup.js`** — Verifies your Node.js environment (`platform`, `arch`, `version`).

### Chapter 02 — JavaScript Basics
- **`05_JS_Basics.js`** — Demonstrates variable declaration with `var` and re-declaration.

### Chapter 03 — Identifiers and Literals
- **`06_Identifier_Rules.js`** — Basic examples of valid and invalid identifier names.
- **`07_Identifier_part2.js`** — Overview of naming conventions: `camelCase`, `PascalCase`, `snake_case`, `SCREAMING_SNAKE_CASE`, and Hungarian notation.
- **`08_Comment.js`** — Examples of single-line (`//`) and multi-line (`/* */`) comments.
- **`js_Identifier_rule.js`** — Comprehensive guide covering all identifier rules, Unicode support, reserved keywords, case sensitivity, and naming conventions.
- **`VS_Code_keyboard_shortcut_mac.md`** — VS Code keyboard shortcuts reference for **macOS**.
- **`VS_Code_keyboard_shortcut_windows.md`** — VS Code keyboard shortcuts reference for **Windows**.
